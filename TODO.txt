    几何观测作为候选目标，进行回环几何校验；校验成功后完成相对位姿
    的高精度解算，并衔接 Node 融合及 PGO 优化。

    设计时明确：
    - path 的邻域选择、分支划分、拼接坐标系和多个候选的尝试策略。
    - 几何校验、相对位姿精解及协方差的接受条件。
    - Node 融合的具体语义，以及与现有 Node 内部 Gaussian 已经局部 BA
      优化并冻结、全局 PGO 只优化 Node 整体位姿的约定如何衔接。
    - 融合后的节点身份、约束重接、重复观测处理和数据库一致性。
    - 失败候选不影响已提交地图；接受后的融合、位姿和约束一致提交。

    验证：覆盖多 path 中部分候选失败、正确候选成功、非对称 SE(3)
    变换方向、误回环拒绝、融合后 PGO 及跨进程恢复；用真实数据评估
    回环成功率和相对位姿精度，不能只凭编译或合成测试宣称提升。
