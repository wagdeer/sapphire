Sapphire 自动几何重定位（2026-11-01）

目标与边界
异常输入触发前端 reset，旧片段封存，新片段独立初始化和建图。后端尝试自动
连接，失败/歧义/预算不足均保留独立坐标分量，不影响继续采集保存。
删除长期概率假设库、支持/反对计数、表面去重账本、出生概率、遗漏质量上界、
Beta-Bernoulli 标定参数及专用实验代码。没有用固定连续成功次数替代它们。

一次查询
候选检索仅安排有限的计算。是否有共同坐标系由已提交的图连通性决定，session
编号本身不能提供位姿初值。已有共同坐标系使用基础空间候选/图位姿初值；否则
使用冻结几何签名和 G3Reg PAGOR/FPFH 初始化。两者共享 Gaussian GICP、
相同几何质量检查、候选比较和图提交。冻结协方差提供法向，不重建 KNN/PCA。

一次查询汇总各历史上下文及各初值中收敛且有足够重叠支持的结果。把变换转成各自图
分量中预测的 query 位姿：同分量中两两接近的解是同一位置解释，不同分量或显著不同
位姿是竞争解释。只要存在不同的竞争解释，就拒绝本次连接。精度未达标的有支撑收敛解仍是未排除
的解释；它不能被接受，也不能被当成不存在。残差仅选择同一解释
的代表，不允许靠“更低残差”排除另一个有支撑的收敛位置。沿用已有对应距离
和旋转尺度判断位姿等价，不引入数据集专用阈值或概率。资源缺失的查询不提交。

搜索是有界近似，不声称枚举了所有地点、证明全局唯一或实现零误拼。几何不可辨识
时允许不连接。单条独立分量间的桥边即使通过图试解，也不构成独立的身份验证。

异步所有权
前端线程独立运行估计器。原后端线程管理 NodeBuilder、Memory、图和数据库；
至多一个后台几何任务只持有冻结 query/target 点云和坐标元数据，不访问这些可变
owner，不持有其锁，不回写前端。没有匹配任务队列；忙时照常保存新节点，任务
结束后可尝试最新节点。在线与归档工具共用几何求解和歧义判断。

目标点云总载荷按现有 path_max_bytes 有界；加载/组装以及图提交仍归后端 owner。
该限制不是进程 RSS 上限。配准任务不带长期状态，也不持有无限历史点云。
后台结果返回后先检查组装子图内部相对位姿是否变化，再在当前图上试解/提交。
归档几何始终冻结。后端 BA、Gaussian fusion 和历史匹配窗口策略已移除，
在线和归档工具均不再修改 batch 内部几何。历史 SAPLID02 只保留读写兼容。

reset 边界在 FIFO 中按 generation 排序：旧冻结帧先处理，新 generation 的首帧
之前封存/切换后端片段。前端只等待边界入队，不等待配准完成或地图对齐。
后端发布与当前 generation 核对，旧片段结果不能作为新里程计的 correction。
无输入时后端以有界等待检查任务结果；退出时先 drain 在途任务再销毁 owner。
存储/必需数据交接保持有界且不静默丢数据：真正的存储吞吐不足仍可能产生背压，
不承诺有限资源下无限输入也永不等待。配准不再占用入库线程或 reset 应答链路。
