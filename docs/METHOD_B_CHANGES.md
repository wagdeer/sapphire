# Method B 独立版变更说明

## 独立构建和运行

提交 `1982d46` 将 `method_b` 整理为只构建和运行 Method B 的分支。从 CMake 目标、运行入口和配置中移除了原来并存的 main 专属管线。应用统一使用 `sapphire::OdometryPipeline`，配置位于 `cfg/cfg_b/`。与 `main` 做 A/B 时，各自检出并编译两个分支，使用相同输入回放。

## 滑窗优化器

体素因子只保留实际有观测的帧，缓存 IMU 预积分的信息矩阵，复用已接受状态的平面特征值和残差。拒绝试探步长时恢复接受状态的缓存。该改动减少了空块计算、重复求逆和重复特征分解，保留原有收敛策略。

## 配置和建图分支

参数按输入输出、传感器、里程计、子图与 BA、PGO 和回环查询分组。激光入口裁剪与子图打包裁剪分别控制原始回波和后端几何。近期地图反馈和反馈前 BA 分别配置，封图 BA 独立执行。对外地图和轨迹始终做重力对齐。

在线子图等到关键帧数和有效平面体素数都达标才封存。结束回放时封存剩余尾段。刚性压缩仍根据几何约束及边界形变判断，超限时保留逐帧位姿与里程计约束。
